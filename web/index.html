Project Objectives (From Presentation)

  • Centralized Platform: Solves WhatsApp/scattered notice spam by providing a single source of truth for FISAT events.
  • Streamlined Bookings: Students register with 1 click; coordinators manage real-time participant capacity.
  • Digital Certificate Hub: Auto-generated accredited e-certificates available for instant download and verification.
  • Pure Java OOP Core: Built using fundamental Java classes, inheritance, polymorphism, and encapsulation.
Core Java Object-Oriented Principles

Java OOP Architecture & Class Diagram Mapping

Direct implementation of the UML diagram from Slide 7 using standard Java (JDK).

1. Abstraction

abstract class User defines common authentication, profile update, and abstract method getRoleDescription().

2. Inheritance

Student extends User, ClubOrganizer extends User, and Hackathon extends Event reuse and extend base functionality.

3. Polymorphism

Method overriding in Hackathon.getDetails() dynamically specializes event information at runtime when invoked through an Event reference.

4. Encapsulation

All model variables (userId, eventId, capacity, etc.) are strictly private with robust accessors/mutators.
